# 项目背景
# 抽取器
## 输入

```json
{
  "file": "学历证书.pdf",
  "files": [
    "学历证书.pdf",
    "成绩单.pdf"
  ],
  "extraction_request": {
    "mode": "multimodal",
    "model": "qwen-vl-max",
    "file_source": {
      "type": "minio",
      "minio": {
        "endpoint": "minio.example.com:9000",
        "bucket": "documents",
        "key": "2026/学历证书.pdf",
        "access_key": "access-key",
        "secret_key": "secret-key",
        "secure": true
      }
    },
    "fields": [
      {
        "name": "name",
        "type": "string",
        "extraction_prompt": "证书持有人姓名",
        "notes": "保持原文，不要推测"
      }
    ],
    "tables": [
      {
        "name": "courses",
        "notes": "课程成绩表",
        "columns": [
          {
            "name": "course_name",
            "type": "string",
            "extraction_prompt": "课程名称",
            "notes": ""
          },
          {
            "name": "score",
            "type": "number",
            "extraction_prompt": "课程成绩",
            "notes": ""
          }
        ]
      }
    ],
    "global_prompts": [
      "无法确认时返回 null"
    ],
    "result_mode": "sync",
    "callback_url": "http://main-service/extract/callback",
    "callback_api_key": "callback-api-key"
  }
}
```

字段含义：

| 字段                  | 含义                                                           |
| ------------------- | ------------------------------------------------------------ |
| `file`              | 单个上传文件。与 `files`、`file_source` 三选一。                          |
| `files`             | 同一材料项的多个上传文件。                                                |
| `mode`              | `multimodal`：文件转图片交给视觉模型；`parsed`：先由外部解析器转 Markdown。必填。      |
| `model`             | 指定模型；不传则使用默认模型。                                              |
| `file_source`       | 不上传文件时，改从 MinIO/S3 获取文件。                                     |
| `fields`            | 普通字段列表，至少要有它或 `tables` 之一。                                   |
| `name`              | 调用方定义的结果 key，如 `name`、`school`、`paper_title`。                |
| `type`              | `string`、`number`、`boolean`，默认 `string`。                     |
| `extraction_prompt` | 对该字段的抽取说明。                                                   |
| `notes`             | 更细的格式或判断规则。                                                  |
| `tables`            | 表格类结果，例如课程、作者、论文列表。                                          |
| `columns`           | 表格每行的列定义，结构与 `fields` 中的单字段相同。                               |
| `global_prompts`    | 对所有字段生效的规则。                                                  |
| `result_mode`       | `sync` 同步返回；`async_poll` 返回任务 ID 后轮询；`async_callback` 完成后回调。 |
| `callback_url`      | 仅 `async_callback` 必填。                                       |
| `callback_api_key`  | 回调请求携带的 `X-API-Key`，可选。                                      |
## 输出

```json
{
  "success": true,
  "data": {
    "name": {
      "value": "张三",
      "source": {
        "pages": [1]
      }
    },
    "courses": {
      "value": [
        {
          "course_name": "高等数学",
          "score": 92
        },
        {
          "course_name": "大学英语",
          "score": 88
        }
      ],
      "source": {
        "pages": [2]
      }
    }
  },
  "error": null,
  "usage": {
    "model": "qwen-vl-max",
    "mode": "multimodal",
    "prompt_tokens": 1200,
    "completion_tokens": 180,
    "total_tokens": 1380
  },
  "metadata": {
    "file_name": "学历证书.pdf",
    "total_pages": 2,
    "batch_count": 1,
    "processing_time_ms": 3200
  }
}
```

输出字段含义：

|字段|含义|
|---|---|
|`success`|是否抽取成功。|
|`data`|抽取结果，key 就是输入 `fields[].name` 或 `tables[].name`。|
|`data.<key>.value`|实际抽到的值；找不到时为 `null`。表格字段则是行数组。|
|`data.<key>.source.pages`|模型认为该值所在的文档页码。|
|`error`|失败原因；成功时为 `null`。|
|`usage`|本次模型、模式与 token 用量。|
|`metadata.file_name`|已处理的文件名。|
|`metadata.total_pages`|文件总页数。|
|`metadata.batch_count`|文件被拆分为多少批交给模型。|
|`metadata.processing_time_ms`|总处理耗时，单位毫秒。|
