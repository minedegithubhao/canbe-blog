# Vue3基础

很多人第一次接触 Vue 3，最先注意到的是：

- 写法变了
- `this` 没了
- 代码好像更自由了

但如果只把 `setup` 理解成“Vue 2 的另一种写法”，学习很快就会卡住。  
真正该理解的是：

> Vue 3 把组件组织方式从“按选项分散”变成了“按功能聚合”。

这里的内容其实已经覆盖了学习 Vue 3 最重要的几层：`setup`、响应式、计算属性、侦听器、生命周期、自定义 hook、组件通信。  
这篇文章就按一个更连贯的学习顺序把它们重新组织起来。

## 一、先理解 `setup` 到底改变了什么

在 Vue 2 的 Options API 里，组件逻辑通常分散在：

- `data`
- `methods`
- `computed`
- `watch`

小组件这样写很直观，但一旦逻辑复杂，同一块功能会被拆得到处都是。

而 `setup` 的核心价值是：

> 同一个功能相关的状态、方法、计算和侦听，可以写在一起。

最基础的例子：

```vue
<script setup lang="ts">
console.log(this) // undefined

let name = '张三'
let age = 18
let tel = '13888888888'

function changeName() {
  name = '李四'
}
</script>
```

这里要立刻注意一件事：

- 变量是普通变量
- 并不是天然响应式

## 二、`<script setup>` 为什么会成为主流

```vue
<script setup lang="ts" name="Person">
import { ref } from 'vue'

const name = ref('张三')
</script>
```

它流行不是因为“更短”，而是因为：

- 样板代码更少
- 更适合配合 TypeScript
- 更方便抽离组合逻辑

## 三、响应式真正的入口：`ref` 和 `reactive`

### 1. `ref` 适合基本类型，也能包对象

```vue
<script setup lang="ts">
import { ref } from 'vue'

let name = ref('张三')
let age = ref(18)
let tel = '13888888888'

function changeName() {
  name.value = '李四'
}

function changeAge() {
  age.value += 1
}

function showTel() {
  alert(tel)
}
</script>
```

这里最重要的不是记语法，而是知道：

- `name` 是一个 `ref` 对象
- 真正响应式的是 `name.value`
- 模板里可以省略 `.value`
- JavaScript 里不能省

### 2. `reactive` 更适合对象和数组

```vue
<script setup lang="ts">
import { reactive } from 'vue'

let car = reactive({ brand: '奔驰', price: 100 })
let games = reactive([
  { id: 'ahsgdyfa01', name: '英雄联盟' },
  { id: 'ahsgdyfa02', name: '王者荣耀' },
  { id: 'ahsgdyfa03', name: '原神' }
])

let obj = reactive({
  a: {
    b: {
      c: {
        d: 666
      }
    }
  }
})
</script>
```

### 3. `ref` 和 `reactive` 怎么选

最实用的判断：

- 基本类型，优先 `ref`
- 对象或数组，优先 `reactive`
- 如果需要统一传递一个值引用，`ref` 更方便

## 四、`computed` 不是语法题，它解决的是派生状态

```vue
<script setup>
import { ref, computed } from 'vue'

const count = ref(0)
const doubleCount = computed(() => count.value * 2)

const list = ref([1, 2, 3, 4, 5, 6, 7, 8])
const filterList = computed(() => list.value.filter(item => item > 2))
</script>
```

`computed` 的关键不是“自动更新”，而是：

> 当一个值可以由另一个值推导出来时，不要重复存储它。

## 五、`watch` 的作用，不是替代 `computed`，而是处理副作用

### 1. 监听单个数据

```vue
<script setup>
import { ref, watch } from 'vue'

const count = ref(0)

watch(count, (newValue, oldValue) => {
  console.log(`count发生了变化，老值为${oldValue},新值为${newValue}`)
})
</script>
```

### 2. 监听多个数据

```vue
<script setup>
import { ref, watch } from 'vue'

const count = ref(0)
const name = ref('cp')

watch([count, name], ([newCount, newName], [oldCount, oldName]) => {
  console.log(newCount, newName, oldCount, oldName)
})
</script>
```

### 3. `immediate`

```vue
watch(count, (newValue, oldValue) => {
  console.log(`count发生了变化，老值为${oldValue},新值为${newValue}`)
}, {
  immediate: true
})
```

### 4. `deep`

```vue
<script setup>
import { ref, watch } from 'vue'

const state = ref({ count: 0 })

watch(state, () => {
  console.log('数据变化了')
}, {
  deep: true
})
</script>
```

如果要一句话区分：

- `computed` 解决“值怎么推导”
- `watch` 解决“变化后要不要做点别的事”

## 六、自定义 Hook 才是 Composition API 真正的工程价值

```ts
export default function useCategory() {
  const menuItems = ref({})

  const articleCategory = async () => {
    let result = await articleCategoryService()
    menuItems.value = result.data
  }

  return {
    menuItems,
    articleCategory
  }
}
```

这一层特别重要，因为它说明 Vue 3 不只是“组件里好写一点”，而是：

> 可以把重复逻辑提炼成组合函数，像模块一样复用。

## 七、组件通信别背诵，要按关系选方案

### 1. 父传子：`defineProps`

```vue
<script setup lang="ts">
const props = defineProps(['msg', 'message', 'count'])
</script>
```

要点只有两个：

- `defineProps` 不需要导入
- 子组件收到的 `props` 是只读的

### 2. 祖传孙：`provide` / `inject`

```vue
<script setup lang="ts">
import { ref, reactive, provide } from 'vue'

let money = ref(100)
let car = reactive({
  brand: '奔驰',
  price: 100
})

function updateMoney(value: number) {
  money.value += value
}

provide('money', money)
provide('car', car)
provide('updateMoney', updateMoney)
</script>
```

### 3. 父组件直接访问子组件能力：`defineExpose`

默认情况下，`<script setup>` 里的内容不会自动暴露给父组件。  
如果确实需要，可以显式开放。

## 八、Vue 3 基础为什么最终都会落到工程化

后半部分已经开始自然进入项目开发：

- Element Plus
- 表单校验
- axios
- 路由
- Pinia
- 持久化插件

例如 Element Plus 挂载：

```ts
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import locale from 'element-plus/dist/locale/zh-cn.js'
import 'element-plus/dist/index.css'
import App from './App.vue'

const app = createApp(App)
app.use(ElementPlus, { locale })
app.mount('#app')
```

Pinia 最小接入：

```ts
import { createPinia } from 'pinia'

const pinia = createPinia()
app.use(pinia)
```

## 最后

如果重新学习 Vue 3，更推荐按下面这个顺序：

1. 先理解 `setup` 和 `<script setup>`
2. 再吃透 `ref`、`reactive`
3. 然后学 `computed`、`watch`
4. 接着理解组件通信
5. 最后进入自定义 hook、路由、状态管理和组件库

Vue 3 真正难的不是语法，而是要建立一个新的组件心智模型。  
一旦这条线打通，后面写项目会顺很多。
